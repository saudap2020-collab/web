# لوحة إنجاز التدريب — مؤشرات

لوحة تعرض الإنجاز العام، وإنجاز كل إدارة، وأسماء الأعضاء والدورات ونسب الإكمال، بالوضعين الفاتح والداكن.

## التحديث التلقائي

- مهمة GitHub Actions (`.github/workflows/sync.yml`) تسحب ملف الإكسل من رابط OneDrive كل ٥ دقائق تقريبًا وتحدّث `members.csv`.
- الصفحة تقرأ `members.csv` وتتحدث كل دقيقة.
- للتحديث فورًا: تبويب **Actions** ← **تحديث بيانات اللوحة** ← **Run workflow**.

## أعمدة الإكسل المطلوبة (الصف الأول)

| الإدارة | الاسم | الدورة | نسبة الإكمال |
|---|---|---|---|

- النسبة رقم (`92` أو `92%`). كل دورة في صف مستقل.
- رابط المشاركة لازم يكون "أي شخص معه الرابط يقدر يشوف".

## تغيير رابط الإكسل

Settings ← Secrets and variables ← Actions ← أضف `EXCEL_SHARE_URL` بالرابط الجديد.
